## Данные группы на графике

* **Вариант**: А (Посещаемость)
* **Данные**: Исходный список из файла преподавателя (28 студентов). Данные обезличены: удалены ФИО, строки перемешаны, студентам присвоены коды S01–S28. Пустые значения (когда студента еще не было в списках) учитываются корректно при расчете процентов.
* **Выводы**:
  1. Общая средняя явка по группе за весь период составила **66.9%**.
  2. Пик посещаемости пришелся на 8 октября (2026-10-08) — явка составила **82.1%**.
  3. Более половины группы, а именно **16 студентов**, имеют общую долю посещений 75% и выше.
* **Проверка**: Явка на первое занятие (2026-09-03) посчитана руками. В списке на тот момент числилось 26 человек (двое еще не были добавлены), из них присутствовало 20. Расчет: `20 / 26 * 100 = 76.9%`. Это полностью совпадает с точкой 76.9% на линейном графике страницы.
* **ИИ**: Использован Gemini. ИИ подготовил веб-страницу, обработал особенности формата CSV из Excel (считывание `1.0` и `0.0`), написал цельный `index.html` со встроенным парсингом CSV, графиками ECharts и адаптивным дизайном, а также рассчитал контрольные значения для ручной проверки.
